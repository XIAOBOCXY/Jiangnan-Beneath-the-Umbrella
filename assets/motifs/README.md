# 纹样素材库

`MotifLibrary.js` 维护稳定的纹样 ID 与素材文件映射。作品数据只保存 `patternId`，所以更换图像文件不会改变已有作品对象、缩放、旋转或环形排列数据。

## 当前素材检查

- `lotus.png`、`west-lake.png`、`koi.png`、`bamboo.png`、`cloud.png` 均为 PNG，尺寸 1254 × 1254，RGBA，含透明像素；当前作为高细节的本地绘画素材草稿使用。
- 仓库里同时保留了对应的 SVG 文件，但绘画器不再将这些简化 SVG 用作上述五种纹样的主素材。
- `water.svg` 是适合连续排列的简洁线饰，当前以 `vector-decoration` 身份保留。它不是工笔成稿；后续可由透明 PNG/WebP 替换。
- 这些已有 PNG 在仓库中没有作者、来源或授权记录。提交公开展示前，请补齐素材来源信息；不要把它们描述成已核实的非遗原作。

## 替换为 Procreate 成稿

1. 导出透明背景 PNG，或使用支持透明通道的 WebP。
2. 将素材放入本目录，保持主体周围透明留白；原始长宽比会在绘制时保留。
3. 在 `js/drawing/MotifLibrary.js` 中更新对应 `src` 和 `format`，保留原 `id`，以兼容历史作品数据。
4. UI 卡片预览路径在根目录 `index.html`。若替换了格式，同步更新对应 `<img src>`。
5. 不要先把素材扁平化到整把伞的背景图；每个纹样应保持独立透明图层，便于缩放、旋转和环形重复。

格式使用浏览器原生 `Image` 解码，当前清单接受 PNG、WebP 和 SVG。SVG 适用于线饰与界面装饰；正式绘画纹样优先选择带透明通道的高分辨率位图。
