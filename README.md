# 西湖绸伞非遗数字展馆

**Jiangnan Beneath the Umbrella** · 沉浸式非遗体验网站

网站以杭州西湖绸伞为文化载体，串联主页、非遗文化、伞面创作和动态作品画廊。工坊保留数字绸面自由绘画、纹样编辑与 2D/3D 联动；主页以可交互的三维绸伞与烟雨湖面建立体验入口，文化页采用可翻页的双页展陈。

## 运行

项目使用原生 HTML、CSS、JavaScript 模块、Canvas 2D 和按需加载的 Three.js。Three.js 0.186.0 核心模块及项目使用的插件已随项目存放在 `vendor/three/`，GPU 水墨和 3D 赏伞不再依赖 jsDelivr。页面资源从当前站点同源加载。在项目根目录执行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 http://localhost:8000/。可使用电脑鼠标、触屏或 Apple Pencil；iPad Safari 建议使用横屏浏览。
桌面和 iPad 横屏采用单屏编辑布局；手机屏幕较窄时，工具会排在画布下方。

## 网站体验

项目由四个页面组成，使用 URL hash 导航：`#home` 首页、`#heritage` 非遗文化、`#studio` 绘制工坊、`#gallery` 作品画廊。页面切换使用 Three.js Shader 转场：近黑色墨层从右侧以不规则液态边缘向左覆盖，完全不透光地遮住旧页面后切页，再向左退去揭露新页面；没有使用 Canvas 2D 或 SVG 遮罩。转场总时长为 0.5 秒，约 0.215 秒时完全遮住页面后切页；开启系统“减少动态效果”后快速完成。

- **首页**：首页不显示顶部品牌横幅。宣纸、远山与多层雾带叠加 Three.js 湖面 Shader；远山、近山、雾带和水面以不同速度缓慢漂移。指针位置直接写入 Shader Uniform，并在同一渲染帧产生局部水滴波前与纹理折射；鼠标路径按约 0.0055 个归一化距离补采样，最多保留 160 个细分路径点，并从最近 1.52 秒的可见水波中均匀抽取 48 个 Shader 样本。浏览器合并的指针事件会继续补齐轨迹，过期波点不再占用采样槽，因此快速移动时水波沿路径连续出现；不绘制独立圆环或墨迹。首页 3D 画布对伞体执行射线命中判断：点到伞体继续旋转/缩放，点到透明留白则由背景接收水滴扰动。绸伞放在右侧独立展示区，模型倾斜、慢速旋转，并可拖动和滚轮缩放。主标题使用本地阿里妈妈刀隶体，诗句与入口按钮使用本地寒蝉活楷体；诗句与按钮共用同一响应式字号，标题、背景、绸伞及布局保持不变。文字保持静止，鼠标视差只作用于伞体和背景，避免字面抖动。三个文字式入口使用墨迹池作为底部点击区域，次级入口悬停时保持透明底色。
- **非遗文化**：采用 12 组双页纸本展陈，含封面和 23 个印刷页，不再纵向滚动阅读。书本按原有横竖比例放大，四个导航按钮置于书本外侧右上角；按钮后方的墨迹通过缓慢流动的渐变与轮廓变化呈现，按钮文字保持白色并置于墨迹前层。六个章节索引签可跳至创制、材料、装饰、贴青、纹样和养护章节，并沿书页两侧外缘显示。索引签固定占位，避免翻页时其余标签上下跳动；翻页开始时标签藏到纸页后，越过中缝后在左侧对应高度显示，回翻时移回右侧。新页内容在纸页越过中缝后显示。书内文字不可选中，鼠标移动会带动宣纸上的淡墨背景。正文、页码和书签在翻页过程同步切换。书本角落不再叠加独立卷角贴图；翻页由纸页正反面旋转表现。书中照片与工艺流程图均采用湖北美术学院湖北省非物质文化遗产研究中心《江南民间手工艺调查——以西湖绸伞为例》的栅格图版，图注改为面向参观者的说明，不展示论文图号或资料链接；外链图片使用 `object-fit: contain` 保持原始宽高比，离线时不可见。该文章页面未明确声明图片开放许可，公开部署前需取得图片使用授权或替换为许可明确的学术图版。西湖绸伞始创于 1932 年、2008 年列入国家级非遗名录，见[中国非物质文化遗产网项目档案](https://www.ihchina.cn/project_details/14578/)；“贴青”及收拢形态参考[杭州工艺美术博物馆专题报道](https://hznews.hangzhou.com.cn/chengshi/content/2016-09/09/content_6290844.htm)。
- **绘制工坊**：沿用现有 Canvas 2D、GPU 湿墨、纹样对象和 Three.js 预览。伞面水墨生成算法与 2D 笔迹未改；柔墨、纤维笔、清晰笔的预设仅作小幅区分。织物选择器初始化时同步三种材质状态，避免控制器方法改名后阻断整站脚本启动。3D 伞面采用近乎全漫反射的哑光丝绸响应：粗糙度为 1、sheen 关闭、镜面项接近零。工坊单独降低环境光与补光，并对浅色无彩绸面施加暖象牙色响应、提高细织起伏的可见度，避免伞面发白；首页灯光、2D 画布和有色绘画纹样不受影响。3D 湿墨叠加整体降权，减小同一笔在 3D 曲面上的浓淡差和扩散感，保持 2D 笔迹不变。材质选择只轻微改变伞面张力、织理和漫反射响应。全屏背景直接运行 shuimo-liuyun 上游的 WebGL 流体模拟代码，页面控制项被隐藏并固定为墨色；指针悬停只向原速度场注入速度，不落颜料，模拟只在工坊可见时运行。伞面绘画仍走原有 UV 湿墨系统；顶部“存入画廊”会把当前稳定伞面纹理存入浏览器本地存储。
- **作品画廊**：青绿雨桥场景占满整个视口，右上角是透明文字导航；空白处可拖动桥景作小幅浏览。独立图层包含水墨远山、反向缓慢漂移的远雾与中景雾、WebGL 湖面、透明石桥后层、最多八位小比例人物、狭窄的桥面前缘遮挡层、保持原始纵横比并裁去空透明区域的底部荷花，以及分层雨丝。人物使用 4×4 图集中的独立行走与驻足帧，沿桥面弧线行走、停顿、转向，相遇时按身体宽度避让，脚底落在可行走的石面上，前缘只轻微遮住鞋底。伞依据对应作品的真实 Three.js 模型预览与握柄锚点固定在举伞手；伞骨在小尺寸预览中按真实模型投影补强；伞盖前景层按真实伞盖网格投影裁切，避免把第二份伞柄或手掌叠到人物身上。右侧“全部绸伞”面板可筛选系统与个人作品、把作品分配给桥上人物，并在二次确认后删除个人作品。点击桥上伞面后，以同一作品 ID 和 UV 纹理打开独立 3D 欣赏；预览与赏伞采用一致的方形画幅、相机、模型姿态和比例，降低进入时图案缩放或偏移。背景在薄雾后继续缓慢运动。人物属于艺术化演绎，不是历史档案复原；素材、图层和运行方式见 `assets/gallery/README.md`。

画廊作品只保存在当前浏览器的 `localStorage`，不会上传服务器或自动公开给其他设备。“存入画廊”新增的个人作品会在此浏览器的“我的作品”筛选中出现。作品纹理、卡片缩略图、桥上伞面预览和 3D 欣赏按作品 ID 对应；桥上人物的作品分配也保存在本地存储。删除个人作品时同步清除其分配关系，并回退到有效作品。`GalleryScene.js` 将远山、雾、人物、桥、水、荷花和雨组织为独立图层；湖面持续以 Three.js WebGL Shader 流动，雨雾与角色行走分开计时。人物脚底依据新桥素材的上缘采样曲线定位；石桥拆成后层和窄前缘层，人物位于两者之间，前缘轻遮鞋底。荷花层按素材自然比例呈现，不压扁宽幅图像。桥面矩形从实时布局读取，桌面与窄屏使用各自的桥面位置和高度。

## UI 与互动水墨背景

页面使用暖纸色、黛青和湖青组成的满幅工作台，顶部操作栏、中央伞面和右侧工具列直接叠放在水墨背景上。按钮有轻量层级和按压反馈；绘画模式、笔刷和织物选项使用成组控件；右侧参数面板收窄并下移，避开顶部导航。纹样分类标签与“纹样分类”标题同排，使用长方形标签，选中时出现墨迹晕开的底色。辅助线与伞面吸附默认开启，不再占用独立按钮；纹样卡片和选择状态保留轻量纸面质感。

顶部不显示作品命名框或分享入口；“空白”操作为“清空”。“存入画廊”会保存当前伞面纹理到本机浏览器，最多保留 12 件近期作品；浏览器存储空间不足时会提示缩小保存或清理站点数据。页面仍不上传作品，也不要求登录。

当前项目是无构建步骤的原生 HTML/CSS/JavaScript H5，控件保留原生语义、事件与现有状态绑定，并以 CSS 实现这些组件模式，不加载 Web Awesome 远程脚本或其他 CDN，也不改变绘画参数含义。放射重复仍是原生 `input[type="range"]`，完整保留 1–14 的整数范围、键盘操作和触屏拖动。控件配色、间距、边框和焦点状态引用 `styles.css` 的全局设计令牌。Uiverse 页面声明其 UI 元素采用 MIT 许可；本项目以 [Italic Emphasis Toggle Switch](https://uiverse.io/uiverse-astronaut/mighty-cobra-14) 为视觉参考，没有复制其源代码。

首页继续由 `HomeLakeScene.js` 以 Three.js WebGLRenderer 和 ShaderMaterial 绘制动态水面及路径水滴；首页诗句与入口按钮使用相同的响应式字号，不改水波或其他布局。`InkWashBackground.js` 按路由惰性显示本地 iframe：工坊 iframe 运行 shuimo-liuyun 上游源码，空白背景指针仅向原速度场注入速度；文化页 iframe 运行 ink-water 上游 Navier–Stokes 解算器，改为透明墨色覆盖层，并沿两条缓慢弯曲轨迹连续注入低浓度墨色与速度，由同一流场带动、扩散和消散；鼠标经过书页时也会带起低浓度墨痕并推动墨场。离开对应页面或切到后台时停止模拟。绘制工坊的伞面笔迹仍走原有 UV 湿墨系统；环境背景与作品纹理分离。

本轮更新：桥面素材按宽幅比例适配视口，桌面保留低矮拱桥，窄屏扩展桥宽以避免纵向拉伸；人物脚点与桥图轮廓使用同一场景坐标换算，桥前缘只遮住鞋底附近。石桥降低饱和度与纹理对比度。WebGL 湖面增加非规则细波、断续反光和雨滴纹理扰动，不再只有均匀横向色带；雨丝增加可见密度，但仍保留远近粗细和透明度差异。画廊加载提示改为清晰的浅色文字。首页水波、绘制系统和跨页面转场未改。

页面切换由 `InkTransition.js` 的 WebGL Shader 实现，不创建 Canvas 2D 绘图上下文。近黑不透光遮罩以分形噪声扰动边缘，按右向左覆盖、全屏遮挡切页、右向左揭幕播放，总时长约 0.5 秒。Three.js 页面背景和转场使用 `setAnimationLoop`、受限设备像素比、减少动态效果支持及资源释放逻辑。

字体通过项目内 `assets/fonts/` 同源加载：标题使用阿里妈妈刀隶体，首页诗句与按钮、文化书页正文及右上导航使用寒蝉活楷体；文化页章节标题继续使用阿里妈妈刀隶体。两种 WOFF2 均在 HTML 中预加载，字体变量仅在首页与文化页覆盖，工坊及其他页面保留原有字体设置。绘制工坊的说明文字和参数标签使用同一界面字体，避免不同字体造成字形跳变。

间距基于 `styles.css` 中的全局 `--spacing` 与 `--space-*` 刻度；界面颜色集中在 Tailwind v4 风格的 `@theme` 和 `:root` 设计令牌中，组件只引用统一的语义变量。背景 Shader 从同一组全局色值读取墨色与湖青。

## 操作

- **自由绘画**：柔墨、纤维笔、清晰和水墨生成共用同一套 GPU 绘制系统，不显示 3D 笔头，使用普通十字光标。柔墨笔迹较宽、只保留轻微湿边；纤维笔使用干笔参数和可见纤维颗粒，不产生晕染；清晰笔为零水量、零流速、零纤维颗粒，保持干爽锐利；只有“水墨生成”保留明显湿墨流动，其参数不变。鼠标按下、触屏落笔或 Apple Pencil 接触后才注入颜料；拖动时以连续线段进入 2D 伞面 UV，并通过圆形遮罩限制范围。松开后湿墨继续晕染约 0.9 秒，再清除速度和湿度场；干燥后的颜料不再漂移或衰减，仍映射到 3D 绸伞。放射重复范围为 1–14；设为 1 重时只绘制一笔，镜像仅在重复数大于 1 时生效。笔迹源线段保存在作品数据中以支持撤销/重做。
- **纹样装饰**：12 枚可选纹样按湖山景致、花卉植物、江南风物、戏曲人物、传统纹饰和伞缘边饰分类。每枚纹样都在注册表中记录对应实物伞照片、论文页码和参考链接；素材是据照片题材与构图重新绘制的透明 PNG 或 SVG，不冒充原伞像素裁片。网页只显示纹样解释，来源资料留在元数据和素材说明中。选中素材后，可在工作纸面内移动、缩放、旋转和环形重复，允许纹样跨出伞缘。
- **环形重复**：选中纹样，调整数量和半径后点击“环形重复”。重复副本由一个数据对象实时生成，可继续统一调整。
- **构图辅助**：辅助线和伞面吸附默认开启，不提供单独开关；辅助线只用于落点提示，不进入导出的作品。纹样可以在伞缘内外自由移动，仍在伞面内的落点会自动对齐到装饰区域。区域是数字编辑提示，不代表传统工艺尺寸规范。
- **示例 / 清空**：示例加载由可编辑纹样对象组成的“荷韵西湖”构图；清空会清除笔迹和纹样。撤销、重做支持绘画、添加、移动、重复、编辑、删除和清空。
- **伞面材质与保存**：选择器控制伞面织物，不控制绘画题材或 UV 图案。三种材质为轻薄乔其纱、细织平纹绸和较密实的密织绸；它们只改变轻微的伞面张力/垂坠、织理密度与漫反射响应。3D 伞面采用暖象牙色、哑光布料着色，不做镜面反光、明显丝光或做旧；工坊 3D 光照只在赏伞视图中减弱高光并让浅色绸面显出暖色，彩色作品纹样保持原色。UV 作品纹理始终保留原有笔触与纹样。顶部“存入画廊”将干燥后的笔迹、纹样与湿墨快照裁切为伞面纹理，写入浏览器本地画廊；不包含编辑辅助线与竹骨结构。
- **2D 绘制 / 3D 赏伞**：状态栏切换视图。3D 模式使用独立 WebGL 预览，保留编辑器中的作品数据；切回 2D 后继续编辑，之后再进入 3D 会刷新伞面贴图。“存入画廊”在 2D 和 3D 模式下都会保存伞面创作纹理，不保存视口截图。
- **收伞 / 开伞**：3D 视图通过“伞面开合”滑杆或“收拢 / 展开”按钮播放开合动画。项目默认加载 Blender 制作的绸伞 GLB：36 根长短竹骨、伞面、伞巢和竹柄使用同一段 `Umbrella Fold` 动画；收伞时同一组竹骨向柄束拢，不会额外长出分离骨架。模型仍是可替换的结构示意，没有布料碰撞模拟。
- **GPU 湿墨与调试**：`InkFluidSystem.js` 与 Three.js 共用 WebGLRenderer，以双缓冲速度场、颜料场和湿度场执行注入、速度输运、颜料输运、压力投影、局部扩散与干燥。每个渲染批次最多合并 32 条 GPU 线段输入，避免放射复制时为每个副本反复切换整套渲染目标。右侧可切换绸面颜料、速度场、颜料密度和湿度场；“测试注入”用于无需绘画验证 GPU 输出。系统是适合 H5 的低分辨率近似，不等同于完整的 Navier–Stokes 流体或真实颜料物理。
- **旋转与缩放**：2D 画布空白处拖动旋转，滚轮以指针为中心缩放；默认比例为 100%，让伞面周围留出工作纸面。伞面可越过原始正方形编辑框显示，画布坐标仍按视图变换反算，绘制位置保持准确。桌面端 2D 和 3D 伞心略向右，给左侧纹样解释留出空白；窄屏 3D 伞心保持居中。3D 预览使用略带侧角的视点，便于观察绸面弧度与竹骨；仍可拖动旋转、滚轮或双指缩放。
- **导入 Blender GLB**：3D 模式点击“导入 Blender GLB”选择单文件 `.glb`。建议伞面网格命名为 `canopy`、`cloth` 或 `fabric` 并提供有效 UV；没有 UV 时程序用水平投影临时映射，并在界面提示需要在 Blender 制作正式 UV。

## 作品数据与渲染

笔迹和纹样对象保存在 ArtworkDocument，Canvas 只作为渲染缓存。纹样对象包含 id、patternId、位置、比例、角度、重复数量、排列半径、朝向和所属区域。环形副本每次绘制时由该对象生成，不会永久压平到像素图层。

画布按 720 × 720 个逻辑单位工作，并按 devicePixelRatio 调整像素缓冲区（最高 2x），控制 iPad 多层 Canvas 的内存占用。自由绘画默认使用 8 重、8px、45% 浓淡；2D 伞面视图初始以 100% 显示。放射重复范围为 1–14；1 重只画单笔，镜像在重复数大于 1 时才参与绘制。环形纹样在中部最多 12 个，外圈小纹样最多 16 个。作品导出只合成绸面、笔迹、纹样、光影和伞骨；不包含选择框与辅助线。

绘画纹样作为独立透明图像加载，保留原始宽高比，以 Canvas 2D 实现移动、缩放、旋转与环形重复；不会再由程序给纹样叠加随机颗粒或模糊来伪造工笔细节。二维预览中的图案仍可与底色层混合，三维伞面则由统一的 Three.js 光照和丝绸材质响应。环形重复采用逐个淡入和轻微缩放。导出画布沿用静态图层合成，不包含鼠标光斑或选择框。

### 2D / 3D 混合渲染

- `ArtworkDocument` 继续保存笔迹和纹样对象，Three.js 不保存或改写作品数据。
- `CanvasManager.getUmbrellaTextureCanvas()` 从二维导出层合成 1024 × 1024 的伞面贴图，裁出绸面圆区域并省略二维竹骨层，避免与 3D 竹骨重叠。CanvasTexture 复用这张离屏 Canvas；编辑过程不会逐帧重建或上传纹理，进入 3D 视图时只在贴图版本变化后更新。
- 默认 3D 伞由 `assets/models/west-lake-umbrella.glb` 加载。绸面网格有径向 UV，并使用 CanvasTexture；模型含 36 组长短竹骨、伞巢、伞心、直竹柄和绸面收拢动画。二维伞骨数量与默认 Blender 模型一致。`tools/create_blender_umbrella.py` 可以在 Blender 中重建 `.blend` 与 `.glb`。程序伞仍作为导入失败时的回退。
- 程序伞的开合采用简化连杆约束而非整伞缩放：伞巢位置确定短骨长度约束，解算主骨角度；伞面顶点与伞缘沿伞骨方向收束，保留 36 道细褶。它呈现西湖绸伞竹骨套合的结构关系，但仍是程序化近似，没有执行布料碰撞或真实竹材关节的有限元模拟。
- GPU 湿墨系统用 128 × 128 速度场、512 × 512 颜料场和 256 × 256 湿度场双缓冲；鼠标线段先映射到伞面 UV，再按 1–14 重放射与镜像派生副本。`ThreeUmbrellaPreview.js` 只负责绸伞场景、材质与 GPU 颜料叠加；鼠标光标由浏览器原生十字样式显示，不再创建圆锥网格、笔头叠加场景或独立动画循环。环境交互与伞面 GPU 湿墨纹理及作品数据隔离：首页湖面扰动由 `HomeLakeScene.js` 的 Three.js Shader 处理；工坊背景用同一 Three.js 场景生成连续流动的墨场，背景指针只扰动场，不注入颜料；文化页的无声全屏墨流由 `InkWashBackground.js` 覆盖背景与书页，并以两条连续游移轨迹注入低浓度墨色；画廊没有背景指针墨迹。伞面绘画仍由原有 UV 水墨系统处理。纤维笔和清晰笔显式设为零水量、零流速，并使用窄边缘抗锯齿轮廓；纤维笔只在笔迹内部保留纤维颗粒，干笔显示层不叠加湿墨光晕；柔墨保留轻湿边，“水墨生成”的湿墨参数不变。速度/颜料注入按最多 32 个副本成批合成；松笔后短时扩散，约 0.9 秒后清理流速与湿度，干墨长期保留。3D 视图把 GPU 颜料纹理映射到与伞面共用几何和 UV 的 PBR 湿墨层。项目还参考 [PavelDoGreat GPU 双缓冲结构](https://github.com/PavelDoGreat/WebGL-Fluid-Simulation)；整体为面向伞面 UV 和作品数据的适配实现，不是逐像素复刻。
- 声光响应使用项目内置的原创 Web Audio 江南氛围乐，不访问系统声音、不要求上传音频，也不需要额外音频文件。用户点击“声光响应”后，古琴感五声音阶拨弦、低音铺底与轻雨质感循环播放；同一音频分析器提取低频能量，驱动伞面微光、绸面粗糙度与背景雾层变化。再次点击暂停音乐和响应。音频由浏览器实时合成，首次播放需用户主动点击；扫描光只在进入 3D 后短暂播放一次。效果属于 Web Audio/WebGL 的轻量近似，不是 TouchDesigner 工程。
- 伞面使用 CanvasTexture、程序生成的细织法线图和 MeshPhysicalMaterial；三个面料预设通过轻微的伞面弧度、织纹起伏、粗糙度与漫反射体现材质差异，不替换作品 UV 图案。绸面采用高粗糙度、低镜面反射；工坊独立降低补光，浅色无彩布面使用暖象牙色调，使乔其纱不呈冷白过曝，彩色纹样保持原有色相。当前是实时着色近似，并非实拍物理材质扫描。
- Three.js/WebGL 在默认示例载入后预热，用户不必等到选择“水墨生成”才等待初始化；模块仍按需加载。HTML import map 指向项目内 `vendor/three/` 的 0.186.0 核心模块和插件，因此三维功能不依赖访问 jsDelivr。`vendor/three/LICENSE` 保留该 npm 包的许可证文本；升级版本时同步替换核心模块、插件及其依赖文件。
- 导入 GLB 时，纹理会应用到命名伞面网格；若缺少有效 UV，会从水平伞面投影补出临时平面 UV（不是径向展开），界面会提示用户制作正式 UV。材质匹配优先看伞面网格名，避免把 silk-rib-seam 等竹骨缝线误认为绸面；导入动画按 GLB 作者数据原样播放，不改写关键帧。默认 Blender 模型的竹骨沿绸面曲率铺设，并使用独立直柄、伞巢和开合动画。
- 3D 预览保存会把当前 WebGL 画面合成到柔和背景并导出 PNG。分享入口与海报预览已移除。

二维编辑视图以 Canvas 图层提供纸面、伞骨、纹样与辅助线；四种自由笔刷统一由 GPU UV 水墨层绘制，Canvas 不叠画第二条线。作品源数据记录起止 UV、速度、颜色、水量和纹理参数，撤销/重做会重新派生对称笔迹并重建 GPU 颜料层；3D 视图直接读取同一颜料纹理。GPU 模拟使用同一输入坐标、批次线段和圆形遮罩，以降低断点、错位及画布外绘制。作品历史最多保留 40 步，并另受约 16 MiB 的序列化快照预算约束；超限时优先丢弃较早的撤销/重做检查点。三维赏伞视图是 WebGL 网格与材质光照，不是 TouchDesigner 工程。模型为 Blender 制作的可编辑原型，不含真实布料碰撞、完整次表面散射或物理颜料模拟。

## 素材说明

`MotifLibrary.js` 是纹样配置注册表。每条素材元数据包含稳定 ID、分类、PNG/WebP/SVG 格式、推荐尺寸、默认重复数、默认单幅放置方式、适用伞面区域与资源状态。分类和卡片由该配置动态生成；新增 PNG/WebP 只需放入素材目录并在注册表新增一项，不需要改绘制算法。PNG/WebP 保留 alpha 和源图宽高比；Canvas 合成结果仍实时提供给 Three.js 的 CanvasTexture。

绘制工坊提供 12 枚有实物照片依据的纹样，其中 9 枚为 SVG 复绘、3 枚为透明 PNG 绘制稿。每个条目均在 `MotifLibrary.js` 记录照片文件名、论文页码和参考链接；旧素材 ID 仅作为隐藏兼容别名保留。来源和重绘范围见 [纹样素材说明](assets/motifs/README.md) 与 [实物照片来源表](assets/heritage/papers/SOURCES.md)。

二维编辑器里的织理、扇区光照、绸面凹影和伞骨是 Canvas 2D 绘制的工作视图；3D 赏伞使用独立的弯曲网格和实体竹骨结构。两种视图共用同一份作品数据。分区仅是数字编辑的构图辅助，不代表传统工艺尺寸规范。

## 伞面材质

伞面选择器是织物材质，不是图案或装饰工艺。三项材质配置是供实时预览使用的视觉参数：乔其纱表现轻薄透气，平纹绸表现柔韧细织，密织绸表现织理更紧密、垂坠稍稳。选材会轻微改变伞冠张力、沿竹骨方向的褶感、织理密度和漫反射响应，不替换用户的 UV 绘画作品，也不向伞面叠加装饰图形。旧版本保存的 `blueCloth` 会自动映射到“密织绸”，确保已有作品仍能读取材质设置。

西湖绸伞的面料与装饰工艺有历史差异：非遗资料记录其伞面会使用丝绸等材料，并介绍画花、刷花、绣花等装饰技艺；乔其纱等轻薄丝料也见于相关工艺资料。界面中的三种材质是对织物触感的数字化表达，不代表非遗名录中的正式材料分类。参考：[中国非物质文化遗产网：西湖绸伞项目档案](https://www.ihchina.cn/project_details/14578/)、[杭州中国伞博物馆展陈介绍](https://ori.hangzhou.com.cn/ornews/content/2023-01/14/content_8448591.htm)。

3D 伞面采用高粗糙度、极低镜面反射和关闭清漆层的漫反射材质；织物纹理以轻微经纬起伏表现，不使用镜面亮带。真实西湖绸伞并非只有纯白伞面：杭州工艺美术博物馆藏品包含绿色乔其纱、四季花机绣实例；展览报道也记录了粉色乔其纱与手绘伞面。白色乔其纱同样存在，因此工坊将无彩的浅色基布处理为温润象牙绢色，并保留绿、粉、墨色纹样各自的色相，不把整把伞做成旧黄或高光塑料感。工坊赏伞使用独立的暖中性柔光：进一步压低环境与补光强度，减少伞心发白；中性浅色布料只在 3D 工坊加入暖绢色校正，且提高细织法线的可见度。切回首页时灯光及绢色校正恢复原状；2D 画布、用户绘画与 UV 纹样不被这层校正改色。3D 湿墨叠加仍保持较均匀的浓淡，边缘不增加深色描边。这里是基于实物资料的实时视觉近似，不是实拍物理材质扫描，也不代表对传统丝绸光泽的定量复原。参考：[杭州工艺美术博物馆藏西湖绸伞藏品图录（Google Arts & Culture）](https://artsandculture.google.com/asset/modern-west-lake-silk-umbrella-with-machine-embroidered-floral-patterns/QwF75JJa1x_dvQ?hl=zh-cn)、[西湖绸伞粉色乔其纱与手绘伞面的展览报道](https://www.thepaper.cn/newsDetail_forward_22910245)、[中国伞博物馆展出的白色乔其纱实例](https://z.hangzhou.com.cn/2023/cjyxwmw/content/content_8453324.htm)。
