# 伞下江南

**Jiangnan Beneath the Umbrella** · 西湖绸伞数字共创 H5

《伞下江南》以杭州西湖绸伞为文化载体，让用户在数字绸面上自由绘画、选择纹样并生成可编辑的环形装饰。设计以“以指为笔，以绸为纸，一笔绘出万千江南”为核心体验。

## 运行

项目使用原生 HTML、CSS、JavaScript 模块、Canvas 2D 和按需加载的 Three.js。Three.js 0.186.0 核心模块及项目使用的插件已随项目存放在 `vendor/three/`，GPU 水墨和 3D 赏伞不再依赖 jsDelivr。页面资源从当前站点同源加载。在项目根目录执行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 http://localhost:8000/。可使用电脑鼠标、触屏或 Apple Pencil；iPad Safari 建议使用横屏浏览。
桌面和 iPad 横屏采用单屏编辑布局；手机屏幕较窄时，工具会排在画布下方。

## UI 与互动水墨背景

页面使用暖纸色、黛青和湖青组成的满幅工作台，顶部操作栏、中央伞面和右侧工具列直接叠放在水墨背景上。此次控件更新参考 [Uiverse 的开源 UI 元素库](https://uiverse.io/) 与 [Web Awesome 组件文档](https://webawesome.com/docs/components)：按钮采用轻量层级和按压反馈；绘画模式、笔刷、织物与方向选项使用成组切换控件；范围控件采用清晰的填充轨道、圆形手柄和少量步进标记；镜像、区域吸附采用 Uiverse 编辑式开关；纹样卡片按 Web Awesome Card 的媒体卡片层级呈现。右侧工具统一使用界面无衬线字体，标题、正文、按钮和数值通过字号与字重建立层级。自由绘画模式只显示笔刷与放射工具，纹样库只在纹样装饰模式显示；分类条支持触屏横滑和鼠标拖动。移除了笔刷说明与画布底部的操作提示，以减少重复信息和侧栏占用。

顶部不再显示作品命名框或分享入口；“空白”操作改为“清空”。“存入画廊”按钮本轮仍沿用导出 PNG 的保存行为，画廊存储功能尚未实现，点击后会明确提示并下载当前 2D 或 3D 作品。

当前项目是无构建步骤的原生 HTML/CSS/JavaScript H5，控件保留原生语义、事件与现有状态绑定，并以 CSS 实现这些组件模式，不加载 Web Awesome 远程脚本或其他 CDN，也不改变绘画参数含义。放射重复仍是原生 `input[type="range"]`，完整保留 1–14 的整数范围、键盘操作和触屏拖动。控件配色、间距、边框和焦点状态引用 `styles.css` 的全局设计令牌。Uiverse 页面声明其 UI 元素采用 MIT 许可；本项目以 [Italic Emphasis Toggle Switch](https://uiverse.io/uiverse-astronaut/mighty-cobra-14) 为视觉参考，没有复制其源代码。

页面底层以“烟雨西湖 · 游墨生花”为方向。纸纹、全屏 SVG 远山与近山、雾带和山水线条是独立背景层，继续缓慢漂移；2D 绘制时减弱，3D 赏伞时柔和增强。鼠标墨迹不参与这些背景层的合成，也不会生成额外灰雾，而是 `InkWashBackground.js` 中单独的一张透明 WebGL 前景层。它保留 [Yakudoo 水墨模拟](https://codepen.io/Yakudoo/pen/bGOMJPw) 的 BufferSim 双缓冲、坐标平滑、噪声扰动、扩散、向下流动和慢慢消散；参考原作的 RGB 循环色已改为单色墨密度场，笔迹中心是黛墨，扩散边缘是烟灰，不会留下彩色轨迹。线宽保持接近参考按下后的较粗状态，但无需按下鼠标。鼠标在空白区域或伞面上闲置移动、拖动旋转时都能看到同一条轨迹；真正开始 2D 绘画或拖动已有纹样时暂停背景轨迹，避免与作品编辑重叠；移到工具栏时清除轨迹，避免墨迹覆盖控件。移除了原先跟随指针绘制的伞面白色径向高光，避免与这条墨迹形成第二层鼠标反馈。背景鼠标层只有这一份透明轨迹，不叠加独立的鼠标光斑或拖影层。实际伞面绘画仍使用普通十字光标。噪声纹理由本地固定种子生成，不依赖远程贴图。背景主色为宣纸白 `#F5F1E8`、烟墨灰 `#777A75`、浓墨黑 `#343936` 与黛青 `#80948D`。这是对参考反馈流程的 H5 适配，不包含原 3D 笔头，也不是完整 Navier–Stokes 流体求解器。WebGL 背景采用限幅的低分辨率渲染；浏览器不支持 WebGL 时使用 SVG 山水和透明 Canvas 兼容绘制。页面动画遵循系统的减少动态效果偏好。

间距基于 `styles.css` 中的全局 `--spacing` 与 `--space-*` 刻度；界面颜色集中在 Tailwind v4 风格的 `@theme` 和 `:root` 设计令牌中，组件只引用统一的语义变量。背景 Shader 从同一组全局色值读取墨色与湖青。

## 操作

- **自由绘画**：柔墨、纤维笔、清晰和水墨生成共用同一套 GPU 绘制系统，不显示 3D 笔头，使用普通十字光标。柔墨笔迹较宽、只保留轻微湿边；纤维笔使用干笔参数和可见纤维颗粒，不产生晕染；清晰笔为零水量、零流速、零纤维颗粒，保持干爽锐利；只有“水墨生成”保留明显湿墨流动，其参数不变。鼠标按下、触屏落笔或 Apple Pencil 接触后才注入颜料；拖动时以连续线段进入 2D 伞面 UV，并通过圆形遮罩限制范围。松开后湿墨继续晕染约 0.9 秒，再清除速度和湿度场；干燥后的颜料不再漂移或衰减，仍映射到 3D 绸伞。放射重复范围为 1–14；设为 1 重时只绘制一笔，镜像仅在重复数大于 1 时生效。笔迹源线段保存在作品数据中以支持撤销/重做。
- **纹样装饰**：纹样库按主体绘画、花卉植物、江南元素、传统纹饰和伞缘边饰分类。选中素材后，在伞面点击一次放置一个对象。主体画默认单幅放置；装饰纹样可按各自元数据预填重复数，再由用户决定是否环形排列。
- **环形重复**：选中纹样，调整数量和半径后点击“环形重复”。重复副本由一个数据对象实时生成，可继续统一调整。
- **构图辅助**：伞面保持俯视圆形，基础图形约占绘画画布直径的 68%；2D 视图初始放大到 112%，让伞体在工作区内更易观察。辅助线标出伞心（0–18%）、中部（22–58%）和外圈（68–82%），区域留白用于分隔主次；这些比例是数字编辑辅助，不代表传统工艺尺寸规范。辅助线不进入 PNG，区域吸附默认开启，可关闭。
- **示例 / 清空**：示例加载由可编辑纹样对象组成的“荷韵西湖”构图；清空会清除笔迹和纹样。撤销、重做支持绘画、添加、移动、重复、编辑、删除和清空。
- **伞面与保存**：可切换素绸、轻纱、蓝印与伞面颜色。顶部“存入画廊”本轮导出当前作品 PNG；真正的作品画廊与作品命名功能暂未实现。
- **2D 绘制 / 3D 赏伞**：状态栏切换视图。3D 模式使用独立 WebGL 预览，保留编辑器中的作品数据；切回 2D 后继续编辑，之后再进入 3D 会刷新伞面贴图。3D 模式的“存入画廊”会导出当前赏伞画面 PNG。
- **收伞 / 开伞**：3D 视图可拖动“开合”滑杆控制开合度，也可按按钮播放约 1.25 秒的动画并中途反向。项目默认加载 Blender 制作的绸伞 GLB：绸面 Shape Key、独立竹骨、短骨、伞巢和连续竹柄带有统一的 `Umbrella Fold` 动画，由 AnimationMixer 按进度驱动。模型仍是可替换的视觉原型，没有布料碰撞模拟；正式工艺模型可替换 GLB。
- **GPU 湿墨与调试**：`InkFluidSystem.js` 与 Three.js 共用 WebGLRenderer，以双缓冲速度场、颜料场和湿度场执行注入、速度输运、颜料输运、压力投影、局部扩散与干燥。每个渲染批次最多合并 32 条 GPU 线段输入，避免放射复制时为每个副本反复切换整套渲染目标。右侧可切换绸面颜料、速度场、颜料密度和湿度场；“测试注入”用于无需绘画验证 GPU 输出。系统是适合 H5 的低分辨率近似，不等同于完整的 Navier–Stokes 流体或真实颜料物理。
- **旋转与缩放**：2D 画布空白处拖动旋转，滚轮以指针为中心缩放；缩放范围为 60%–1000%，伞面可越过原始正方形编辑框显示，画布坐标仍按视图变换反算，放大后绘制位置不会错位。编辑器正方形容器不再被最大高度压扁，确保 2D 伞面始终保持正圆。窄屏下放大留白以上下对称方式预留，并补偿布局重排造成的舞台中心变化，避免反复缩放后作品漂移；浏览器滚动锚定不会意外移动编辑舞台。3D 模型默认接近俯视以呈现圆形伞面，仍可拖动旋转观察曲率；滚轮或触屏双指缩放，视角范围受限；3D 预览在显示时低速自动旋转，切回 2D 后停止渲染循环。
- **导入 Blender GLB**：3D 模式点击“导入 Blender GLB”选择单文件 `.glb`。建议伞面网格命名为 `canopy`、`cloth` 或 `fabric` 并提供有效 UV；没有 UV 时程序用水平投影临时映射，并在界面提示需要在 Blender 制作正式 UV。

## 作品数据与渲染

笔迹和纹样对象保存在 ArtworkDocument，Canvas 只作为渲染缓存。纹样对象包含 id、patternId、位置、比例、角度、重复数量、排列半径、朝向和所属区域。环形副本每次绘制时由该对象生成，不会永久压平到像素图层。

画布按 720 × 720 个逻辑单位工作，并按 devicePixelRatio 调整像素缓冲区（最高 2x），控制 iPad 多层 Canvas 的内存占用。自由绘画默认使用 8 重、8px、45% 浓淡；2D 伞面视图初始以 112% 显示，滚轮范围仍为 60%–1000%。放射重复范围为 1–14，滑块轨道显示每个整数步进点，当前值由标题旁的数值实时显示；1 重只画单笔，镜像在重复数大于 1 时才参与绘制。环形纹样在中部最多 12 个，外圈小纹样最多 16 个。作品导出只合成绸面、笔迹、纹样、光影和伞骨；不包含选择框与辅助环带。

绘画纹样作为独立透明图像加载，保留原始宽高比，以 Canvas 2D 实现移动、缩放、旋转与环形重复；不会再由程序给纹样叠加随机颗粒或模糊来伪造工笔细节。二维预览中的图案仍可与底色层混合，三维伞面则由统一的 Three.js 光照和丝绸材质响应。环形重复采用逐个淡入和轻微缩放。导出画布沿用静态图层合成，不包含鼠标光斑或选择框。

### 2D / 3D 混合渲染

- `ArtworkDocument` 继续保存笔迹和纹样对象，Three.js 不保存或改写作品数据。
- `CanvasManager.getUmbrellaTextureCanvas()` 从二维导出层合成 1024 × 1024 的伞面贴图，裁出绸面圆区域并省略二维竹骨层，避免与 3D 竹骨重叠。CanvasTexture 复用这张离屏 Canvas；编辑过程不会逐帧重建或上传纹理，进入 3D 视图时只在贴图版本变化后更新。
- 默认 3D 伞由 `assets/models/west-lake-umbrella.glb` 加载。绸面网格有径向 UV，并使用 CanvasTexture；模型含 32 组长短竹骨、伞巢、伞心、直竹柄和绸面收拢动画。二维伞骨数量与默认 Blender 模型一致。`tools/create_blender_umbrella.py` 可以在 Blender 中重建 `.blend` 与 `.glb`。程序伞仍作为导入失败时的回退。
- 程序伞的开合采用简化连杆约束而非整伞缩放：伞巢位置确定短骨长度约束，解算主骨角度；伞面顶点与伞缘沿伞骨方向收束，保留 32 道细褶。它呈现西湖绸伞竹骨套合的结构关系，但仍是程序化近似，没有执行布料碰撞或真实竹材关节的有限元模拟。
- GPU 湿墨系统用 128 × 128 速度场、512 × 512 颜料场和 256 × 256 湿度场双缓冲；鼠标线段先映射到伞面 UV，再按 1–14 重放射与镜像派生副本。`ThreeUmbrellaPreview.js` 只负责绸伞场景、材质与 GPU 颜料叠加；鼠标光标由浏览器原生十字样式显示，不再创建圆锥网格、笔头叠加场景或独立动画循环。页面背景 `InkWashBackground.js` 使用一组由两个纹理构成的 WebGL ping-pong 双缓冲：逐帧平滑鼠标坐标、噪声方向扰动、四向 blur、water diffusion 与 persistence 参数按 Yakudoo 的 BufferSim 步骤运行；反馈纹理存储单通道语义的中性墨密度，输出时映射为黛墨中心和烟灰边缘的透明度轨迹，与纸纹、山水及雾气分层。轨迹可以覆盖画布和 3D 伞面，但实际 2D 绘画或拖动纹样期间暂停，工具栏上的指针移动会清除轨迹。重力沿屏幕向下的 UV 方向拉伸墨迹。墨色不使用参考原作的三路相移 RGB 循环，由本地生成的噪声纹理替代远程图片。兼容模式用透明 Canvas 单色线段平滑补点。纤维笔和清晰笔显式设为零水量、零流速，并使用窄边缘抗锯齿轮廓；纤维笔只在笔迹内部保留纤维颗粒，干笔显示层不叠加湿墨光晕；柔墨保留轻湿边，“水墨生成”的湿墨参数不变。速度/颜料注入按最多 32 个副本成批合成；松笔后短时扩散，约 0.9 秒后清理流速与湿度，干墨长期保留。3D 视图把 GPU 颜料纹理映射到与伞面共用几何和 UV 的 PBR 湿墨层。项目还参考 [PavelDoGreat GPU 双缓冲结构](https://github.com/PavelDoGreat/WebGL-Fluid-Simulation)；整体为面向伞面 UV 和作品数据的适配实现，不是逐像素复刻。
- 声光响应使用项目内置的原创 Web Audio 江南氛围乐，不访问系统声音、不要求上传音频，也不需要额外音频文件。用户点击“声光响应”后，古琴感五声音阶拨弦、低音铺底与轻雨质感循环播放；同一音频分析器提取低频能量，驱动伞面微光、绸面粗糙度与背景雾层变化。再次点击暂停音乐和响应。音频由浏览器实时合成，首次播放需用户主动点击；扫描光只在进入 3D 后短暂播放一次。效果属于 Web Audio/WebGL 的轻量近似，不是 TouchDesigner 工程。
- 伞面使用 CanvasTexture、程序生成的细织法线图和 MeshPhysicalMaterial；场景使用柔和环境光与方向光。纹理法线和绸缎高光是实时着色近似，并非实拍物理材质扫描。
- Three.js/WebGL 在默认示例载入后预热，用户不必等到选择“水墨生成”才等待初始化；模块仍按需加载。HTML import map 指向项目内 `vendor/three/` 的 0.186.0 核心模块和插件，因此三维功能不依赖访问 jsDelivr。`vendor/three/LICENSE` 保留该 npm 包的许可证文本；升级版本时同步替换核心模块、插件及其依赖文件。
- 导入 GLB 时，纹理会应用到命名伞面网格；若缺少有效 UV，会从水平伞面投影补出临时平面 UV（不是径向展开），界面会提示用户制作正式 UV。材质匹配优先看伞面网格名，避免把 silk-rib-seam 等竹骨缝线误认为绸面；导入动画按 GLB 作者数据原样播放，不改写关键帧。默认 Blender 模型的竹骨沿绸面曲率铺设，并使用独立直柄、伞巢和开合动画。
- 3D 预览保存会把当前 WebGL 画面合成到柔和背景并导出 PNG。分享入口与海报预览已移除。

二维编辑视图以 Canvas 图层提供纸面、伞骨、纹样与辅助线；四种自由笔刷统一由 GPU UV 水墨层绘制，Canvas 不叠画第二条线。作品源数据记录起止 UV、速度、颜色、水量和纹理参数，撤销/重做会重新派生对称笔迹并重建 GPU 颜料层；3D 视图直接读取同一颜料纹理。GPU 模拟使用同一输入坐标、批次线段和圆形遮罩，以降低断点、错位及画布外绘制。作品历史最多保留 40 步，并另受约 16 MiB 的序列化快照预算约束；超限时优先丢弃较早的撤销/重做检查点。三维赏伞视图是 WebGL 网格与材质光照，不是 TouchDesigner 工程。模型为 Blender 制作的可编辑原型，不含真实布料碰撞、完整次表面散射或物理颜料模拟。

## 素材说明

`MotifLibrary.js` 是纹样配置注册表。每条素材元数据包含稳定 ID、分类、PNG/WebP/SVG 格式、推荐尺寸、默认重复数、默认单幅放置方式、适用伞面区域与资源状态。分类和卡片由该配置动态生成；新增 PNG/WebP 只需放入素材目录并在注册表新增一项，不需要改绘制算法。PNG/WebP 保留 alpha 和源图宽高比；Canvas 合成结果仍实时提供给 Three.js 的 CanvasTexture。

现有五张透明 PNG（1254 × 1254，RGBA）全部保留，分别归入主体绘画、花卉植物和江南元素等分类；`water.svg` 作为边饰线稿注册。其余原有 SVG 资源仍保留在目录中，没有被删除或自动填充为卡片。当前素材的来源及授权未记录，仍作为已有草稿管理；正式发布前应补充作者与授权信息。添加流程见 [纹样素材说明](assets/motifs/README.md)。

二维编辑器里的织理、扇区光照、绸面凹影和伞骨是 Canvas 2D 绘制的工作视图；3D 赏伞使用独立的弯曲网格和实体竹骨结构。两种视图共用同一份作品数据。分区仅是数字编辑的构图辅助，不代表传统工艺尺寸规范。
